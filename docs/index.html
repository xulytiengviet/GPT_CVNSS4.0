3. Huấn luyện trên máy cá nhân

uv sync
uv run python -m cvnss.cli prepare --mode unicode
uv run python -m cvnss.cli prepare --mode cvnss
uv run python -m cvnss.cli tokenizer --mode unicode
uv run python -m cvnss.cli tokenizer --mode cvnss
uv run python -m cvnss.cli train --mode unicode --device cpu
uv run python -m cvnss.cli infer --mode unicode --prompt "Xin chào!"

Thay unicode bằng cvnss để chạy thí nghiệm tương ứng. Tập 50 cặp có sẵn chỉ là dữ liệu khởi động, không đủ đánh giá chất lượng chatbot.

4. Giới hạn và nguồn gốc
